## Root Cause

Prime OS canonical COS routes already existed:

- `/ecom/cos/oms/:id`
- `/ecom/cos/fulfillment/jobs/:id`

But legacy UI links still pointed to:

- `/orders/:id`
- `/fulfillment/jobs/:id`

Only base legacy redirects existed:

- `/orders` -> `/ecom/cos/oms`
- `/fulfillment` -> `/ecom/cos/fulfillment`

The dynamic legacy routes were missing, so React Router fell through to the global `*` route and redirected to `/overview`.

## Fix

Added a small reusable redirect component:

- `app/src/components/routing/LegacyEntityRedirect.tsx`

Added dynamic legacy aliases:

- `/orders/:id` -> `/ecom/cos/oms/:id`
- `/fulfillment/jobs/:id` -> `/ecom/cos/fulfillment/jobs/:id`

## Regression Coverage
